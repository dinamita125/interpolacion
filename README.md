# NuméricaLab

Sistema web académico para interpolación y aproximación matemática. Incluye interpolación lineal por tramos, Lagrange, Newton y ajuste lineal por mínimos cuadrados.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalación, servidor ni conexión a Internet.

## Funciones

- Validación de pares ordenados y resultados numéricos.
- Gráfica interactiva con identificación de datos y estimación.
- Procedimiento matemático paso a paso.
- Comparación entre los cuatro métodos.
- Exportación CSV, PNG y reporte imprimible.
- Manual integrado y manual completo imprimible.
- Diseño adaptable a móvil y tema claro/oscuro.

## Estructura

- `index.html`: aplicación principal y manual rápido.
- `script.js`: métodos numéricos, validación, gráfica y exportaciones.
- `styles.css`: diseño adaptable, temas y animaciones.
- `manual.html`: manual completo de usuario.

Proyecto académico de Métodos Numéricos · Universidad Amazónica de Pando.
